# AI Quiz Maker

## 1. 프로젝트 소개
사용자가 입력한 주제를 바탕으로 AI가 객관식 퀴즈를 생성하는 프로그램입니다.

## 2. 주요 기능
- 주제별 AI 퀴즈 생성
- 객관식 보기 제공
- 사용자 답안 제출 및 자동 채점
- 정답과 해설 제공

## 3. 개발 환경
- Python
- Visual Studio Code
- Streamlit
- Google Gemini API
- Git / GitHub

## 4. 실행 방법
1. 필요한 라이브러리를 설치합니다.
2. .env 파일에 Gemini API 키를 설정합니다.
3. 터미널에서 streamlit run app.py를 실행합니다.

## 5. 기대 효과
학습자가 원하는 주제의 퀴즈를 빠르게 만들고
문제 풀이와 해설을 통해 학습 내용을 복습할 수 있습니다.
